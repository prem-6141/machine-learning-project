# Diabetes Prediction Using Machine Learning

## 📌 Project Overview

This project uses **Machine Learning** to predict whether a person is likely to have diabetes based on medical and health-related parameters.

The model is trained using a diabetes dataset and learns patterns from features such as glucose level, blood pressure, BMI, age, and other health measurements. The trained model can then be used to make predictions for new patient data.

## 🎯 Objectives

* Predict the likelihood of diabetes using Machine Learning.
* Analyze important health-related factors associated with diabetes.
* Train and evaluate a classification model.
* Provide an easy-to-use prediction system.
* Understand the practical application of Machine Learning in healthcare.

## 📊 Dataset

The project uses a diabetes dataset containing medical attributes and a target variable indicating whether diabetes is present.

### Main Features

| Feature                  | Description                    |
| ------------------------ | ------------------------------ |
| Pregnancies              | Number of pregnancies          |
| Glucose                  | Plasma glucose concentration   |
| BloodPressure            | Diastolic blood pressure       |
| SkinThickness            | Skin fold thickness            |
| Insulin                  | Insulin level                  |
| BMI                      | Body Mass Index                |
| DiabetesPedigreeFunction | Diabetes hereditary risk score |
| Age                      | Age of the patient             |
| Outcome                  | Diabetes prediction result     |
